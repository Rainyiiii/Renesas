# RA8P1 摄像头数据集采集

该功能已集成到现有摄像头、YOLO、触摸和分拣工程，不需要烧录单独固件。

## 准备 TF 卡

1. 使用板载 TF 卡槽，不需要外接 GPIO。
2. 将 TF 卡格式化为 FAT32。当前固件不支持 exFAT。
3. 建议断电插卡，再给 RA8P1 上电。

板载卡槽使用 SDHI0 四线模式：

| SDHI0 信号 | RA8P1 引脚 |
| --- | --- |
| DAT3 | P111 |
| DAT2 | PD01 |
| DAT1 | PD02 |
| DAT0 | PD03 |
| CMD | PD04 |
| CLK | PD05 |
| CD | PD07 |

FSP 中已经配置 `g_sdmmc0`、DMAC0 通道 0 和卡检测中断，不需要再次手工添加。

## 屏幕操作

正常页面底部从左到右有四个按钮：

1. 开始识别和分拣
2. 暂停
3. 停止
4. 进入数据集采集

进入数据集页面后，底部四个按钮变为：

1. 类别：每按一次在 `H/K/O/R` 之间切换
2. 单拍：保存当前完整摄像头帧
3. 自动：开启或关闭连续采集，每 10 个有效视频帧保存一次
4. 返回：关闭自动采集并回到停止页面

类别与模型顺序一致：

| 字母 | 目录 | 类别 |
| --- | --- | --- |
| H | HARM | 有害垃圾 |
| K | KITCHEN | 厨余垃圾 |
| O | OTHER | 其他垃圾 |
| R | RECOVER | 可回收物 |

顶部会显示 `SD READY`、当前类别、自动采集状态和各类别累计数量。常见错误状态：

| 屏幕状态 | 含义 |
| --- | --- |
| SD NO CARD | 未检测到 TF 卡 |
| SD CARD ERR | SDHI 初始化失败或卡通信失败 |
| SD FAT ERR | 不是 FAT32/FAT16，或文件系统损坏 |
| SD WRITE ERR | 写文件失败，常见原因是卡满、接触不良或写入时拔卡 |

### 一直显示 SD NO CARD

核心板原理图第 6 页中，JTF 的机械检测脚为低有效。插卡后信号链应为：

```text
JTF pin 9 SD0CD = 0V
  -> U602 pin 4 TXB_OE = 高电平
  -> U601 电平转换打开
  -> MCU PD07 = 低电平
```

固件同时检查 SDHI 的 `SDCDMON` 和 PD07 原始电平。可以用万用表依次检查：

1. JTF pin 4 对地应为 3.3V。
2. R601 下端的 `SD0CD`：不插卡约 3.3V，插卡后约 0V。
3. U602 pin 4 的 `TXB_OE`：不插卡约 0V，插卡后应接近 VCC。
4. U601 pin 9（PD07 侧）：插卡后应为低电平。

测量贴片芯片引脚时只用细表笔轻触，避免相邻引脚短路。如果插卡后第 2 步仍为高电平，优先检查卡是否插到底以及 JTF 卡座检测触点；第 2 步正常但第 3 步不正常，则检查 U602 和其 VCC；前三步正常但屏幕仍显示 `SD NO CARD`，则检查 U601 的第 8 通道及 PD07 焊接。

## 文件位置

默认每次拍摄保存一张模型输入尺寸图片：

```text
DATASET/
  IMG192/
    HARM/00000001.BMP
    KITCHEN/00000001.BMP
    OTHER/00000001.BMP
    RECOVER/00000001.BMP
```

- `IMG192`：192x192、24 位 BMP，缩放算法与当前 NPU 输入一致，可直接作为训练数据。
- 为了避免按快门时长时间停帧，`RAW` 原图保存默认关闭。需要同时保存 320x240 原图时，可把 `dataset_storage.c` 中的 `DATASET_SAVE_RAW` 改为 `1U`。
- 固件启动后会扫描已有编号并继续递增，不会从 1 覆盖旧数据。

关闭自动采集后，等顶部数量增加且预览恢复刷新，再断电取卡。不要在保存过程中直接拔卡。

## e2 studio 烧录

1. 在 e2 studio 中打开工程 `rainy`。
2. 可正常执行 `Generate Project Content`，SDHI0 和 DMAC0 已写入 `configuration.xml`。
3. 选择 `Debug` 配置并执行 `Build Project`。
4. 使用原来的 `rainy Debug_Flat` 调试配置下载，不需要 CMD 或另一份诊断固件。

P083 style='2': 摘 要
P084: 针对校园教学楼、食堂等公共投放点在人工垃圾分类中存在错投率高、值守成本高，以及基于通用计算机或云端服务器的视觉方案体积大、网络依赖强、控制链路长等工程问题，本文设计一套基于瑞萨RA8P1的轻量化AI视觉感知与智能分拣平台。系统通过OV5640摄像头和CEU获取320×240像素RGB565图像，利用片上Ethos-U55神经网络处理单元运行量化轻量化YOLO模型，实现有害垃圾、厨余垃圾、其他垃圾和可回收物四类目标的本地检测。软件采用双缓冲采集、双尺度解码、同类非极大值抑制和连续帧稳定判定，并以非阻塞状态机驱动步进电机与连续旋转舵机完成输送、定位、推出、复位和清空确认。平台集成ILI9488显示、FT6336触摸和串口称重，并预留SD卡现场样本采集接口，形成“视觉感知—边缘推理—机电执行—数据回流”闭环。在500±50 lx、目标距离10±2 cm的基准条件下，每类100个独立样本的四分类总体识别正确率为87.8%，宏平均F1为89.2%；动作触发时延P95为14.8 ms，每类30次机电闭环测试的总体分拣成功率为96.7%。
P085: 关键词：瑞萨RA8P1微控制器；嵌入式边缘智能；目标检测；垃圾分类；神经网络处理单元；机电分拣
P088: Lightweight AI Visual Perception Platform Based on Renesas RA8P1
P089: Abstract: To address mis-sorting and labor-intensive supervision at public refuse drop-off points in campus buildings and canteens, as well as the large size, network dependence, and long control path of PC- or cloud-based vision systems, a lightweight AI visual perception and intelligent sorting platform is developed on the Renesas RA8P1 microcontroller. An OV5640 camera and the on-chip Capture Engine Unit acquire 320 × 240 RGB565 images. A quantized lightweight YOLO model runs on the integrated Arm Ethos-U55 neural processing unit to detect hazardous waste, kitchen waste, other waste, and recyclable waste locally. Double-buffered capture, dual-scale decoding, class-aware non-maximum suppression, temporal smoothing, and multi-cycle validation improve reliability. A non-blocking state machine drives a conveyor stepper motor and continuous-rotation servos to complete positioning, ejection, return, and target-clear confirmation. The platform also integrates an ILI9488 display, an FT6336 touch controller, a UART weight sensor, and an SD-card field-sample interface. Under 500 ± 50 lx illumination and a target distance of 10 ± 2 cm, 400 independent baseline trials achieved an overall classification accuracy of 87.8% and a macro-average F1 score of 89.2%. The P95 action-trigger latency was 14.8 ms, and 120 closed-loop sorting trials achieved a success rate of 96.7%.
P090: Keywords: Renesas RA8P1; embedded edge intelligence; object detection; waste classification; neural processing unit; electromechanical sorting
P093 style='2': 作品概述
P094: 1.1 研究背景与设计动机
P095: 随着生活垃圾分类制度持续推进，公共场所对自动识别、自动投放和分类统计的需求不断增加。现有低成本方案多采用颜色传感器、金属传感器或固定规则进行判断，面对外观差异大、形态不规则、背景复杂的生活垃圾时适应性不足。基于通用计算机或云端服务器的视觉方案虽然识别能力较强，但通常存在体积大、功耗高、网络依赖强和部署成本较高的问题。
P096: 本作品以“单片瑞萨 MCU 完成感知、推理与控制”为核心目标，充分利用 RA8P1 的高性能处理能力、片上 Ethos-U55 神经网络处理单元以及丰富的外设接口，将摄像头采集、轻量化目标检测、触摸显示、称重、数据存储和电机控制集中在一个嵌入式平台上。该设计既验证了 AI 推理在资源受限边缘设备上的可行性，也为后续构建低成本、可离线运行的智能分类终端提供工程基础。

P101: 1.3 作品特色与应用前景
P102: 1）单芯片闭环：感知、推理、交互、存储和执行集中运行于RA8P1，无需外部微型计算机或云端服务器。
P103: 2）多外设协同：CEU双缓冲、显示分块传输、触摸降频轮询及SD写入空闲窗口共同降低总线争用。

P108 style='2': 作品设计与实现
P109: 2.1 总体方案
P110: 系统由视觉感知单元、边缘推理单元、人机交互单元、称重单元、数据存储单元和机电执行单元组成。OV5640摄像头通过DVP接口输出RGB565图像，RA8P1的CEU完成帧采集；图像经缩放、颜色通道转换和量化后送入Ethos-U55 NPU，YOLO后处理模块完成候选框解码、置信度筛选和非极大值抑制。分类结果进入机电控制状态机，驱动输送电机和对应舵机完成分拣。ILI9488显示屏用于实时预览和状态显示，FT6336提供触摸操作。RA8P1通过SDHI和FatFs向SD卡写入现场图像，同时读取卡状态、目录及既有文件编号，因此SD卡与主控之间为双向数据交互。系统总体结构如图1所示。

P120: 2.3 图像采集与显示
P121: 2.3.1 OV5640配置与启动自检
P122: 系统通过软件SCCB配置OV5640。上电后先控制PWDN与RESET完成硬件复位，再读取0x300A和0x300B芯片标识寄存器；仅在返回0x56和0x40时继续写入初始化表。摄像头输出320×240 RGB565，关闭JPEG和MIPI通道，采用DVP连接CEU。驱动将无应答、标识错误及寄存器写入失败设置为不同返回值，主程序以不同屏幕颜色区分故障阶段。
P123: 2.3.2 CEU双缓冲与恢复机制
P124: 两个帧缓冲区均为320×240×2 B并按32 B边界对齐。CEU采集一个缓冲区时，系统处理上一完整帧，实现采集与推理/显示的时间重叠。回调函数记录帧结束、CRAM溢出和防火墙事件；轻微异常优先重新启动采集，连续软恢复失败达到8次后执行CEU关闭、重新打开和缓冲区复位，避免偶发错误导致永久停机。
P125: 2.3.3 SPI显示与带宽控制
P126: ILI9488工作于4线SPI和18 bit RGB666模式。显示驱动将摄像头低字节在前的RGB565逐像素转换为RGB666，并按8行块写入320×240预览区域；顶部112行为状态面板，底部为触摸按键区。状态面板每4帧或状态变化时刷新，降低频繁文字更新造成的SPI占用。SPI传输设置完成回调和超时恢复，超时或传输中止后关闭并重新打开SPI实例。
P127: 2.4 人机交互与运行模式
P128: FT6336初始化时先复位控制器，并直接读取SDA、SCL输入电平判断总线是否被拉低；随后通过I²C读取芯片ID。底部控制区划分为4个宽约80像素的按键，支持屏幕180°安装方向的坐标兼容。普通模式四键分别为运行、暂停、停止和数据集；数据集模式四键分别为切换类别、单次采集、自动采集和返回。触摸仅在“抬起→按下”的边沿执行一次动作，避免长按重复触发。
P129: 2.5 轻量化YOLO推理与后处理
P130: 2.5.1 输入预处理
P131: 模型输入为192×192、BGR、NCHW排列的有符号8 bit量化数据。预处理从320×240 RGB565帧按最近邻方式采样，直接拆分蓝、绿、红通道并写入模型输入指针，不建立整帧RGB888中间图像。输入张量本身占用192×192×3=110592 B。
P132: 2.5.2 双尺度解码与置信度计算
P133: 模型提供12×12和6×6两个尺度，每个尺度含3组锚框。对于每个网格单元，后处理先求四分类Softmax最大类别概率，再与对应锚框的Sigmoid目标置信度相乘。边界框中心由网格偏移和步长恢复，宽高由锚框及平方尺度恢复，最后映射至320×240坐标。候选显示阈值为0.35，候选池最多24个。
P134: 2.5.3 非极大值抑制与时序平滑
P135: 候选框按得分降序排列，同类别框交并比大于0.40时抑制低分框，最终最多保留8个检测结果。当前框与上一帧同类别框交并比超过0.20时，以当前结果0.70、历史结果0.30进行坐标和分数平滑。系统选择最终得分最高的目标作为机电控制输入；执行机构使用更高的0.45阈值，并要求连续3个周期同类，从而将“可视化检测”与“安全动作触发”分离。图像采集与推理调度关系如图2所示。

P138: 2.6 机电分拣控制
P139: 2.6.1 步进电机和舵机驱动
P140: 输送步进电机由GPT输出默认900 Hz、50%占空比脉冲，方向由GPIO控制，软件可在20 Hz～20000 Hz范围调整。连续旋转舵机PWM周期为20 ms，0.5 ms～2.5 ms脉宽映射到0°～270°控制值，135°对应停止，0°和270°对应反向与正向。系统配置左右主舵机及一个备用通道，并提供停止状态下的主备路由切换接口。
P141: 2.6.2 非阻塞状态机
P142: 系统采用WAITING、POSITIONING、EJECTING、CLOSING、RETURNING和CLEARING状态。近端类别确认后立即停止输送并驱动对应舵机；远端类别继续输送1100 ms后推出。舵机推出和反向复位各1350 ms，随后等待250 ms重新启动输送。只有连续4个处理周期未检测到目标才回到等待状态。时间判断基于DWT周期计数器，主循环不使用长时间阻塞延时，因此摄像头、显示和异常处理可持续运行。状态转移如图3所示。

P145: 2.7 称重、存储与现场数据闭环
P146: 2.7.1 称重数据解析
P147: 称重模块经UART逐字节接收4 B数据帧，帧头为0xFF，帧尾为0xFE，中间两字节组成16 bit有符号原始值；工程保留原系统4倍标定系数，并将结果限制在int16_t范围。串口校验、帧错误或溢出时中止接收、清空索引并重新启动。称重为可选功能，其初始化失败不阻断核心视觉链路。
P148: 2.7.2 SD卡数据存储软件设计
P149: 系统针对现场数据回流需求，设计了基于SDHI驱动和FatFs的本地存储模块。软件流程包括SD驱动打开、卡状态检测、介质初始化、文件系统挂载、目录创建、已有文件扫描和递增文件命名。图像保存模块能够将320×240 RGB565图像缩放为192×192，并转换为24 bit BGR格式的BMP数据。
P150: 为便于调试，程序设置挂载、介质初始化、文件打开、分块写入和文件关闭等阶段码，并对无卡、响应异常、超时和文件系统异常进行分类。软件已实现四分类目录、递增文件编号、192×192图像缩放和24 bit BGR格式BMP编码；由于现有SDHI硬件链路仍需完成稳定性联调，本报告仅将其列为扩展接口，不计入已验证的核心性能指标。该处理既保留现场数据回流能力，也避免将未稳定通过的写卡功能纳入整机结论。
P151: 2.8 软件总体流程与资源估算
P152: 系统软件总体流程如图4所示。上电后依次初始化显示、触摸、摄像头、CEU、NPU、执行机构和称重模块，并将所有运动输出置于安全状态。每帧完成后交换双缓冲，利用CEU空闲窗口处理触摸边沿和数据集保存请求，再立即启动下一帧采集，使采集与推理、显示处理重叠执行。

P232 style='2': 4. 创新性说明
P233: 本作品的第一项创新是将摄像头采集、YOLO 目标检测、触摸显示、数据存储和机电分拣集中运行在瑞萨 RA8P1 单片 MCU 上。系统直接调用片上 Ethos-U55 NPU 执行量化模型，相比依赖外部微型计算机或云端服务器的常见方案，具有体积小、离线运行、数据不出设备和实时控制链路短等优势。
P234: 第二项创新是面向嵌入式多外设并发场景设计的协同调度机制。工程采用 CEU 双缓冲，在帧完成后的空闲窗口处理触摸和 SD 卡写入，避免软件 I²C 与 SDHI 传输干扰摄像头 DMA；显示驱动采用分块传输和低频状态面板刷新，在有限带宽下兼顾实时预览与交互。
P235: 第三项创新是从单纯的检测显示扩展为视觉识别与机电执行闭环。检测结果经过置信度筛选和连续帧稳定判定后驱动非阻塞状态机，保证识别、显示和执行能够协同运行。系统还预留了现场数据采集的软件架构，为后续完成SD卡硬件联调和模型迭代提供基础，但该扩展功能当前尚未完成稳定写入验证。
P236: 第四项创新是模块化容错设计。触摸、称重和 SD 卡均具有独立状态检测，非核心模块故障不会阻塞视觉主功能；摄像头采集具有软恢复和完整重启两级机制，执行机构还预留步进电机和舵机主备输出切换接口，从而提升系统的工程可维护性。
P239 style='2': 5. 总结
P240: 本作品完成了视觉采集、边缘推理、触摸交互、状态显示、称重接入和机电分拣等主要功能，在单片瑞萨RA8P1上形成从图像输入到分类执行的本地闭环。基准条件下四分类总体识别正确率为87.8%，宏平均F1为89.2%，动作触发P95时延为14.8 ms；机电闭环总体分拣成功率为96.7%，说明轻量化模型、连续帧判定和非阻塞控制能够协同工作。
P241: 工程通过CEU双缓冲、显示分块传输、分阶段错误码、软恢复/完整重启和安全输出策略，降低多外设并发及局部故障对主功能的影响。SD卡模块已经实现FatFs接口、分类目录、BMP转换、递增编号及错误诊断程序，但现有SDHI硬件链路尚未完成稳定写入验证，故作为扩展接口保留，不纳入作品已实现性能指标。
P242: 后续将优先完善SDHI卡检测、电平转换和介质初始化联调，并补充连续写入、掉电续存与异常恢复测试；同时扩充低照度、强反光、遮挡和相似背景样本，开展量化感知训练和锚框重聚类。机电部分可增加可控补光、限位、堵转和入口检测，进一步提高复杂环境与连续投放条件下的稳定性。

P254: 4. Ethos-U55推理、双尺度解码与时序平滑
P255: uint32_t yolo_detector_infer(const uint8_t *frame_rgb565)
{
    detection_t previous[YOLO_MAX_DETECTIONS];
    uint32_t previous_count = g_detection_count;
    for (uint32_t i = 0U; i < previous_count; i++) previous[i] = g_detections[i];

    uint32_t candidate_count = 0U;
    prepare_input(frame_rgb565);
    RunModelQuantized(false);

    decode_scale(GetModelOutputPtr_reg_s22_70462_70750(),
                 GetModelOutputPtr_obj_s22_70463_70748(),
                 GetModelOutputPtr_cls_s22_70464_70746(), 12U, 0U, &candidate_count);
    decode_scale(GetModelOutputPtr_reg_s11_70465_70749(),
                 GetModelOutputPtr_obj_s11_70466_70747(),
                 GetModelOutputPtr_cls_s11_70467_70745(), 6U, 1U, &candidate_count);

    g_detection_count = apply_nms(candidate_count);
    for (uint32_t i = 0U; i < g_detection_count; i++)
    {
        int best = -1;
        float best_iou = 0.20f;
        for (uint32_t j = 0U; j < previous_count; j++)
        {
            if (g_detections[i].class_id != previous[j].class_id) continue;
            float iou = intersection_over_union(&g_detections[i], &previous[j]);
            if (iou > best_iou)
            {
                best_iou = iou;
                best = (int) j;
            }
        }
        if (best >= 0)
        {
            const float old_weight = 0.30f;
            const float new_weight = 0.70f;
            g_detections[i].x0 = new_weight * g_detections[i].x0 + old_weight * previous[best].x0;
            g_detections[i].y0 = new_weight * g_detections[i].y0 + old_weight * previous[best].y0;
            g_detections[i].x1 = new_weight * g_detections[i].x1 + old_weight * previous[best].x1;
            g_detections[i].y1 = new_weight * g_detections[i].y1 + old_weight * previous[best].y1;
            g_detections[i].score = new_weight * g_detections[i].score + old_weight * previous[best].score;
        }
    }
    return g_detection_count;
}
P256: 5. 连续帧触发与非阻塞分拣状态机
P257: void machine_control_process(bool detection_valid, uint8_t class_id, float confidence)
{
    if (!g_initialized || (MACHINE_MODE_RUNNING != g_status.mode))
    {
        return;
    }

    switch (g_status.sort_state)
    {
        case MACHINE_SORT_WAITING:
            if (detection_valid && (class_id < 4U) && (confidence >= DETECTION_MIN_SCORE))
            {
                if (g_candidate_class == class_id)
                {
                    if (g_candidate_ticks < 0xFFU)
                    {
                        g_candidate_ticks++;
                    }
                }
                else
                {
                    g_candidate_class = class_id;
                    g_candidate_ticks = 1U;
                }

                if (g_candidate_ticks >= DETECTION_STABLE_TICKS)
                {
                    begin_sort(class_id);
                }
            }
            else
            {
                g_candidate_class = 0xFFU;
                g_candidate_ticks = 0U;
            }
            break;

        case MACHINE_SORT_POSITIONING:
            if (state_elapsed(FAR_CLASS_TRAVEL_MS))
            {
                machine_stepper_stop();
                sorting_servo_start();
            }
            break;

        case MACHINE_SORT_EJECTING:
            if (state_elapsed(SERVO_TURN_MS))
            {
                machine_servo_output_t servo = sorting_servo_output(g_status.active_class);
                machine_servo_set(servo, sorting_forward_first(g_status.active_class) ?
                                  CONTINUOUS_REV_ANGLE : CONTINUOUS_FWD_ANGLE);
                sort_state_set(MACHINE_SORT_CLOSING);
            }
            break;

        case MACHINE_SORT_CLOSING:
            if (state_elapsed(SERVO_TURN_MS))
            {
                machine_servo_set(sorting_servo_output(g_status.active_class), CONTINUOUS_STOP_ANGLE);
                g_status.sorted_count[g_status.active_class]++;
                sort_state_set(MACHINE_SORT_RETURNING);
            }
            break;

        case MACHINE_SORT_RETURNING:
            if (state_elapsed(SERVO_RETURN_WAIT_MS))
            {
                machine_stepper_run(MACHINE_STEPPER_FORWARD, STEPPER_DEFAULT_HZ);
                g_status.sort_state = MACHINE_SORT_CLEARING;
                g_clear_ticks = 0U;
            }
            break;

        case MACHINE_SORT_CLEARING:
            if (!detection_valid)
            {
                if (g_clear_ticks < 0xFFU)
                {
                    g_clear_ticks++;
                }
            }
            else
            {
                g_clear_ticks = 0U;
            }

            if (g_clear_ticks >= CLEAR_DETECTION_TICKS)
            {
                g_status.active_class = 0xFFU;
                g_status.sort_state = MACHINE_SORT_WAITING;
                g_candidate_class = 0xFFU;
                g_candidate_ticks = 0U;
            }
            break;

        case MACHINE_SORT_STOPPED:
        case MACHINE_SORT_FAULT:
        default:
            break;
    }
}
